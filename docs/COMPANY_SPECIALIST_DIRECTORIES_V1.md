# Каталоги компаний и специалистов на главном сайте — концепция V1

Связанные задачи: https://github.com/Yumis84/Otzovik/issues/3 ; https://github.com/Yumis84/otzovik-company-profile/pull/15

## Решение владельца (2026-10-14)
На основном сайте Отзыв.com предусмотреть самостоятельный список компаний и отдельный каталог специалистов с фильтрами. Единый поиск может искать по обоим типам, но результаты должны явно различаться.

## Предлагаемый UX
- На главной: две явные точки входа «Компании» и «Специалисты».
- Каталог компаний: отрасль/категория, город, услуги, наличие опубликованных отзывов.
- Каталог специалистов: профессия, специализация, город, услуги, наличие опубликованных отзывов. Фильтры строить только по реально заполненным разрешённым полям.
- Карточка результата специалиста: публичное имя, заявленная профессия, город, специализация, ссылка на самостоятельный профиль. Не показывать «подтверждён» без независимой проверки квалификации.
- Один аккаунт может владеть компанией и самостоятельным профилем специалиста; каталог не должен смешивать владение с профессиональной аффилиацией.
- Связь специалиста с компанией откладывается до этапа после V1.

## Технические ограничения
- Только опубликованные профили с действующим согласием специалиста могут попадать в индекс, sitemap и выдачу.
- Не индексировать черновики, отозванные профили и закрытые персональные данные.
- Источник данных и API каталога согласовать после аудита RPC, прав доступа и механизма публикации.
- Текущий главный сайт и маршруты компаний сохранять без изменений до отдельного PR.
- Не рассчитывать агрегированные рейтинги специалистов до готовой модерации и политики достоверности отзывов.

## Acceptance
1. Входы «Компании» и «Специалисты» ведут в соответствующие каталоги.
2. Фильтры специалистов работают по профессии, специализации и городу.
3. Компания не отображается как специалист и наоборот.
4. Черновик или снятый с публикации специалист отсутствует в каталоге и sitemap.
5. Существующие профили компаний и регистрация продолжают работать.

Статус: спецификация, не реализовано. Без изменений production.
